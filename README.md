# Netcheck-application

I created an application with claudecode that probes IP addresses. this application performs pings, traceroutes, DNS checks and checks which ports are open. The application also allows for users to upload their API keys from either Anthropic or OpenAI in order to receive AI analysis on the report of the probes.


## optional step

Enter your API key if you wish to receive AI analysis on the outcomes of the probes
